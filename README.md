# ecoclock-website                                                                                                                                                                                                
                                                                                                                                                                                                                    
  Landing emocional del proyecto [Eco'clock 2026](https://ecoclock.org).                                                                                                                                            
                                                                                                                                                                                                                    
  ## Proyecto técnico                                                                                                                                                                                               
                                                                                                                                                                                                                    
  La red distribuida vive en:                                                                                                                                                                                       
                                                                                                                                                                                                                    
  🔗 [ecoclock-network](https://github.com/veldanigr/ecoclock-network) — servidor, cliente, GUI y binarios para unirse a la red.                                                                                    
                                                                                                                                                                                                                    
  ## Despliegue                                                                                                                                                                                                     
                                                                                                                                                                                                                    
  Este sitio se sirve automáticamente desde Netlify en [ecoclock.org](https://ecoclock.org).                                                                                                                        
                                                                                                                                                                                                                    
  El sitio técnico (descargas y documentación) vive en [download.ecoclock.org](https://download.ecoclock.org), servido vía GitHub Pages desde el repo `ecoclock-network`.                                           
                                                                                                                                                                                                                    
  ## Stack                                                                                                                                                                                                          
                                                                                                                                                                                                                    
  HTML + CSS estáticos + [i18next](https://www.i18next.com/) para internacionalización. Sin build, sin dependencias de runtime (i18next va bundled).
